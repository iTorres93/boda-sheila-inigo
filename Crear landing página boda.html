¡Perfecto! Crear una landing page para tu boda y alojarla en GitHub Pages es una excelente idea: es gratuito, fácil de mantener, y accesible desde cualquier dispositivo. Aquí tienes una guía paso a paso para hacerlo:

🎯 1. Planifica el contenido

Define lo que quieres incluir en la página. Algunas secciones típicas:

  • Nombres de los novios y fecha

  • Contador regresivo

  • Historia de amor (opcional)

  • Detalles del evento (hora, lugar, dress code)

  • Confirmación de asistencia (formulario)

  • Galería de fotos

  • Mapa de ubicación (Google Maps)

  • Lista de regalos (opcional)

🧑‍💻 2. Crea el repositorio en GitHub

  1. Ve a GitHub y crea una cuenta si no tienes una.

  2. Haz clic en “New repository”.

    • Nombre: nombre.github.io (esto activa GitHub Pages automáticamente)

    • Hazlo público (o privado si usas GitHub Pro)

    • Inicializa con un README.md

🌐 3. Desarrolla tu landing page

Puedes crear un solo archivo index.html o usar una estructura más organizada con HTML, CSS y JS. Aquí tienes un ejemplo básico de index.html:

html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Nuestra Boda</title>
  <style>
    body { font-family: sans-serif; text-align: center; background: #f9f3f3; }
    h1 { color: #d36c6c; }
    .section { margin: 2em 0; }
  </style>
</head>
<body>
  <h1>¡Nos casamos!</h1>
  <p class="section">Ana & Luis - 15 de noviembre de 2025</p>
  <div class="section">
    <h2>Detalles del Evento</h2>
    <p>📍 Hacienda El Sol, 4:00 PM</p>
  </div>
  <div class="section">
    <h2>Confirmar Asistencia</h2>
    <a href="https://forms.gle/tu-formulario">Haz clic aquí para confirmar</a>
  </div>
</body>
</html>

💾 4. Sube tu código a GitHub

  1. En tu repositorio, ve a "Add file" > "Upload files"

  2. Sube tu archivo index.html

  3. Haz commit

🚀 5. Activa GitHub Pages

  1. Ve a la pestaña Settings del repositorio

  2. Busca la sección Pages

  3. Selecciona la rama main y carpeta / (root)

  4. Guarda y GitHub generará la URL de tu sitio: https://tuusuario.github.io

✅ 6. Revisa y comparte

Espera unos segundos y visita la URL. Puedes compartirla con tus invitados o incluso personalizarla con tu propio dominio si lo deseas.

  <script>
    const countdown = () => {
      const eventDate = new Date("2025-10-11T17:00:00");
      const now = new Date();
      const diff = eventDate - now;

      if (diff <= 0) {
        document.getElementById("countdown").innerHTML = "¡Ya estamos celebrando!";
        return;
      }

      const days = Math.floor(diff / (1000 * 60 * 60 * 24));
      const hours = Math.floor((diff / (1000 * 60 * 60)) % 24);
      const minutes = Math.floor((diff / (1000 * 60)) % 60);
      const seconds = Math.floor((diff / 1000) % 60);

      document.getElementById("countdown").innerHTML =
        `${days} días ${hours}h ${minutes}m ${seconds}s`;
    };

    setInterval(countdown, 1000);
    countdown();
  </script>

  • El contador regresivo se actualiza cada segundo.

Perfecto, aquí tienes las instrucciones paso a paso para subir tu web de boda a GitHub Pages:

🛠️ PASO 1: Crea un repositorio en GitHub

  1. Ve a https://github.com e inicia sesión.

  2. Haz clic en el botón “+” > New repository.

  3. Completa así:

    • Repository name: boda-sheila-inigo (o el nombre que prefieras)

    • Descripción: Nuestra boda - Sheila & Iñigo - 11 de octubre 2025

    • Marca ✅ “Public”

    • (Opcional) Marca ✅ “Add a README file”

  4. Haz clic en Create repository

📂 PASO 2: Sube el archivo index.html

  1. En la página de tu repositorio, haz clic en “Add file” > “Upload files”

  2. Sube el archivo index.html (el que te proporcioné).

  3. Baja y haz clic en el botón “Commit changes”.

🌐 PASO 3: Activa GitHub Pages

  1. Dentro de tu repositorio, haz clic en la pestaña “Settings” (arriba a la derecha).

  2. En el menú lateral, baja hasta “Pages” (o “Pages & Deployment”).

  3. En la sección Source, selecciona:

    • Branch: main

    • Folder: / (root)

  4. Haz clic en Save

⚠️ Espera unos segundos y aparecerá un mensaje con la URL donde estará tu sitio, algo así como:

csharp
Your site is live at https://tuusuario.github.io/boda-sheila-inigo/

¡Y listo! Tu página web de boda ya estará publicada.

🎁 OPCIONAL: Personaliza tu URL

Si tienes un dominio personalizado (como sheilayinigo.com), puedo ayudarte a configurarlo también con GitHub Pages.
